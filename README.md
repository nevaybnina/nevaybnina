# nevaybnina

Сайт-таймер обратного отсчёта для команды. Первая версия — счётчик до
Markswebb Mobile Web Banking Rank 2026.

## Что где лежит

- `data/events.js` — здесь **дата, название и текст события**. Это единственный
  файл, который обычно нужно менять руками.
- `components/EventCountdown.js` — логика таймера и вёрстка страницы.
- `app/globals.css` — весь визуальный стиль (цвета, шрифты, анимации).
- `app/page.js` — какая страница что показывает.

## Как поменять дату или текст события

Откройте `data/events.js` на GitHub (кнопка с карандашом на странице файла) и
поправьте нужные поля:

- `eventName` — название события
- `eventSub` — короткая подпись под названием
- `dateMoscow` — дата и время **по Санкт-Петербургу**, формат `'2026-09-17T11:00:00'`
- `displayDate` — как дата подписана на странице, например `'17 сентября, 11:00'`
- `about` — список абзацев в блоке «Справка»

Сохраните изменение (Commit changes) — Vercel сам пересоберёт и обновит сайт
за 1-2 минуты.

## Локальный запуск (не обязательно)

Если когда-нибудь понадобится открыть проект на своём компьютере:

```
npm install
npm run dev
```

Сайт откроется на http://localhost:3000
